# 🚀 Advanced Log Archive Tool

A production-ready Bash script designed for Linux environments to compress server logs, manage retention policies, maintain audit histories, and schedule automated backups.

## 📋 Features
- **Dual Mode:** Supports both CLI arguments and an interactive menu.
- **Smart Compression:** Archives logs into timestamped `.tar.gz` format.
- **Audit Logging:** Keeps a detailed history record in `archive_history.log`.
- **Retention Policy:** Automatically cleans up old archives.
- **Cron Scheduling:** Integrates with Linux cron jobs for automated runs.
- **Cloud Backup Ready:** Optional support for uploading archives to AWS S3.

## 🛠️ Usage
Run the script manually by passing your log directory:
```bash
./log-archive.sh /path/to/logs
